# Font strategy

No third-party font binaries are redistributed in this archive. The site uses a careful system-font stack (`Inter`, `Noto Sans Arabic`, Segoe UI, Tahoma, Arial) so it remains readable and works offline without silently shipping unlicensed font files. Add locally licensed WOFF2 files here only after confirming their license, then update `assets/css/site.css` and `assets/css/owner.css` with `@font-face` declarations.
