# صورة الواجهة / Hero photo

ضع صورتك الشخصية هنا باسم **`me.jpg`** (أو `me.jpeg` أو `me.png` أو `me.webp`) — الموقع يكتشفها تلقائيًا ويعرضها في الواجهة الرئيسية.

خطوات الرفع من GitHub:

1. افتح المستودع على GitHub واذهب إلى مجلد `assets/images`.
2. اضغط **Add file → Upload files**.
3. اختر الصورة وأعد تسميتها إلى `me.jpg` قبل الرفع.
4. احفظ التغيير في فرع `main`.

بديل أسرع: من **لوحة المالك → الهوية والمظهر → صورة الواجهة** اضغط «رفع صورة»، وستُحفظ في Supabase Storage وتظهر فورًا.

ملاحظات:
- المقاس المقترح: صورة رأسية أو مربعة، عرض 1200px على الأقل.
- الأنواع المدعومة: JPG وPNG وWebP.
- إذا لم توجد صورة، يظهر إطار أنيق بحرفَي «KH» بدلًا منها.
