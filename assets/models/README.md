# مجسمي الشخصي / Personal 3D model

ضع ملف مجسمك ثلاثي الأبعاد هنا باسم **`me.glb`** — الموقع يحمّله تلقائيًا ويعرضه في مشهد «مجسمي الشخصي» بدل الأشكال البرمجية.

## كيف ترفعه؟

1. من GitHub: افتح هذا المجلد (`assets/models`) ثم **Add file → Upload files**.
2. اختر ملفك بصيغة `.glb` وأعد تسميته `me.glb` قبل الرفع.
3. اضغط **Commit changes**.
4. بعد دقيقة تقريبًا، حدّث الصفحة الرئيسية — سيظهر مجسمك في المشهد.

## ملاحظات

- الصيغة: **GLB** (binary glTF 2.0) فقط. ملفات `.gltf` مع مجلد textures لا تُحمَّل.
- الحجم: يفضَّل أقل من **25 ميجابايت** ليعمل بسرعة على الهواتف.
- الموقع يوسّط المجسم ويحجّمه تلقائيًا داخل المشهد، فلا تقلق من المقاس أو نقطة الأصل.
- إن كان المجسم بلا خامات (textures)، سيظهر بلون فاتح مع إضاءة المشهد.
- إذا لم يوجد `me.glb`، يستخدم الموقع `khaled-digital-core.glb` كبديل.

## روابط بديلة

يمكنك أيضًا وضع أي رابط GLB مباشر في لوحة المالك: **الهوية والمظهر → المشهد ثلاثي الأبعاد → رابط موديل مخصص**.
